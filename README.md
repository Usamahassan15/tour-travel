# Tour Travel Website

A premium, modern, and responsive travel agency website built with
Next.js, TypeScript, Tailwind CSS, and Supabase.

## Features

- Premium travel agency UI
- Tour packages and destinations
- Special deals and discounts
- Travel enquiry system
- WhatsApp enquiry integration
- Visa services
- Hotel and flight booking sections
- Blog and FAQ system
- Customer reviews
- Destination and tour search
- Wishlist and recently viewed tours
- Admin dashboard
- Booking/enquiry management
- SEO optimized pages
- Dynamic metadata
- JSON-LD structured data
- Responsive design
- Performance optimization
- Authentication and role-based access

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- ShadCN UI
- Framer Motion
- Supabase
- Docker

## SEO

- Server-side rendering
- Dynamic metadata
